# 云效流水线查询扩展设计

## 目标

在现有 `yunxiao-project-lifecycle` skill 中接入官方 Yunxiao MCP 的
`pipeline-management` 工具集，支持流水线、运行实例、执行任务和任务日志的
查询。

## 范围

- 查询流水线列表和流水线详情。
- 查询最新运行、运行历史和指定运行详情。
- 查询运行任务、任务历史和任务日志，并对日志中的敏感信息做最小必要脱敏。
- 复用现有组织绑定、能力检查和只读失败语义。

## 边界

- 本次不接入触发、取消、重试、创建、修改、删除流水线，也不接入部署、资源、标签或权限管理。
- 不改变 `yunxiao.toml` 格式，不创建第二套 Yunxiao API 客户端。
- 流水线和运行目标必须通过稳定 ID 或唯一查询结果解析，不使用同名对象的第一条结果。

## 实现位置

- 更新 `SKILL.md`、MCP setup 和 lifecycle policy，补充流水线只读工具与操作规则。
- 更新诊断脚本默认 toolset 和流水线能力检查。
- 更新 doctor 测试，覆盖流水线工具缺失和默认 URL 校验。

## 验收

1. 默认 MCP URL 包含 `pipeline-management`，且诊断能检查流水线只读工具。
2. 缺少流水线工具时，诊断结果明确为 `CAPABILITY_MISSING`。
3. skill 明确流水线查询、运行状态、任务历史、日志的工具路径和安全边界。
4. 不引入新的凭据、Endpoint、绑定格式或 API 客户端。
